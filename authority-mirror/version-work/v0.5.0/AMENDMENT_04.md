# v0.5.0 Amendment 04：受控生物再投入、可调整摆放与长休续控记录

- **状态：** `Approved / Frozen — Implementation Authorized`
- **批准：** User / `2026-08-28`，明确确认“本次优化的方向已经明确，可以执行”。
- **适用范围：** 对已实施的 Amendment 03 作有限交互与关联生命周期补充；不修改 ABC、Amendment 03 或任何冻结历史。

## 批准范围

1. **受控生物再次投入。** 已接受到控制者 CharacterSheet 的 `controlled` 与 `permanent-controlled` 受控生物，在新的遭遇准备阶段可像普通关联单位一样，从明确的 UnitTemplate 创建新的、独立的 CombatantInstance。每场战斗只创建一个新实例；长期卡只保存关联和控制历史。已到期、解除或失控的关系不提供此入口，但历史保留，DM 仍可从单位库独立加入对应模板。
2. **死亡后四选一入口。** 四个结果按钮恒定置于“DM 确定复活”面板之前；选择只切换未提交的本地面板，不写入会话。
3. **新实例的地图摆放。** S2A、S2B、S2C 进入地图后显示临时预览棋子。DM 可在空位间反复拖动；只有点击“确认摆放并生成”才执行原子提交。尸体、其他棋子、完整 footprint 和边界持续作为 guard；取消零写入。
4. **长休续控记录。** 登记一次长休时，DM 可逐个确认“已在到期前续控一次”的 `one-long-rest` 关系。确认后重置为下一次长休的剩余计数，并追加 `control-renewed` 审计记录；未确认者照常到期为 `expired-uncontrolled`。这不是法术施放、资源消耗或规则合法性验证。

## 明确不做

- 不自动准入或执行 Animate Dead、Create Undead 或任何具体法术；不验证资格、材料、法术位、目标数或精确 24 小时计时。
- 不实现法术专属的“施法者后立即行动”、共享回合或独立先攻规则。该能力必须逐法术以 Rules Baseline 准入后另行授权。
- 不把受控关系转为原尸体 PC 的复活、后继角色卡或玩家控制权。
- 不进入 Review、Release、Archive、Commit、Push、部署或公开发布。

## 验证要求

- 自动测试覆盖可再次投入、失控入口关闭、无重复实例、预览拖动不持久化、确认前占格拒绝、四选一固定顺序，以及续控与未续控混合结算。
- 仍需隔离浏览器 origin 的 User/DM Human Acceptance；不得使用真实用户 localStorage 作为测试夹具。
