# v0.6.0 Amendment 01：结构化法术裁定工作台

- **状态：** `Approved / Frozen — Implementation Authorized`
- **批准：** User / `2026-08-31` / “可以批准执行，本次amendment把上面的需求一并写上，并直接进行implementation”
- **适用范围：** 在 v0.6.0 已实施的三结果卡和八法术非阻塞提示上，补充结构化裁定资料、渐进式 UI 与预览；不改写冻结 ABC 或历史版本材料。

## 批准范围

1. 每张结果卡先提供“法术/依据”选择器，只显示适用的八法术或“自定义依据”。选择后生成该法术的紧凑简报：中文名、环阶、施法时间、距离、推荐结果、关键建议和“不自动核验”边界。
2. 每个法术定义可配置的 `SpellRulingProfile`：来源引用、简报、推荐值和结果专属裁定字段。新增法术或字段只需增加 Profile，不重构死亡后对象 Schema。
3. 裁定字段采用视觉化单选分段控件，不使用密集的裸 radio 列表。每项显示建议值，并要求 DM 在“采用建议 / DM 改判 / 不追踪 / 未知”或材料对应四种处理之一作出明确选择；只有改判或自定义时显示输入框。
4. 只在当前法术显示 3–5 个关键字段；其余字段置于“更多裁定资料”。所有适用字段已选后生成结构化预览，显示建议与最终裁定、对象、地图、先攻、资源和控制关系变化；取消不写入。
5. 桌面端使用裁定资料与实时预览双栏；窄屏退化为单栏和预览进度条。法术简报、裁定卡、预览卡复用现有深色卡片视觉，不新增页面或模态流程。
6. 回生术、死者复活、复生术、完全复生术、转生术、克隆术、活化死尸、唤起亡灵和遗体防腐分别按已准入的 PHB 2024 Entry 配置；遗体防腐仍只作为辅助记录。

## 明确不做

- 不校验施法资格、时间、距离、材料库存、灵魂、尸体资格、合法性或 Campaign Time。
- 不自动执行 HP、状态、种族、Template、数量、升环、命令、控制或 24 小时/120 日计算；Profile 的建议只由 DM 选择或改判后记录。
- 不引入全量法术库、怪物资料库、经济系统、玩家权限或新的顶层死亡结果。
- 不进入 Review、Release、Archive、Commit、Push、部署或公开发布。

## 验证要求

- 自动测试覆盖法术 Profile、结果过滤、关键字段、单选状态、改判值、未完成预览、完整预览、取消零写入和现有 v0.5.0/v0.6.0 回归。
- 浏览器 Human Acceptance 检查默认简报、裁定卡、桌面/窄屏布局、预览清晰度和 DM 改判不阻塞。
