## 0. 交付定位

`v0.6.0` 是 DM 跑团辅助交付，不是电子化 D&D 游戏或完整规则引擎。产品职责是：向 DM 提供八个具体法术的简明规则提示，在 DM 作出决定后，正确关联死亡角色、原身体、新身体/新形态、长期角色卡、战斗实例、控制者、受控不死生物、地图、先攻、可选资源记录与顺序事件。

法术条件、材料、资格、灵魂、时间、尸体状态和剧情身份均不得成为不可覆写的合法性 Gate。DM 可以采用规则建议、明确改判、标记不适用、不追踪、未知或使用自定义依据。系统只严格保护数据身份、引用隔离、确认原子性、幂等、写回边界和事件历史。

本 ABC 的批准只冻结范围、UX、数据关系、测试与回退合同，不授权产品代码、分支、Commit、Push、Review、Release、Archive、部署或公开发布。

## 1. A——目标与实施范围

### A-1 单一主 Slice

本交付只使用一个 `v0.6.0-S1`：在 v0.5.0 已实现的死亡后结果、独立角色卡、地图摆放、先攻、控制关系和补偿撤销基础上，统一三种顶层结果、八个中文法术提示模板、自定义依据、规则提示折叠、变更预览和 v0.5.0 旧事件兼容。

不得把三个顶层结果、八个法术或兼容工作拆成可互相独立授权的功能交付。Implementation 必须作为同一主 Slice整体实现和验收。

### A-2 三种顶层结果

死亡后处理入口固定为三张结果卡：

1. **恢复原身体**：恢复死亡 PC 的原 CombatantInstance；
2. **以新身体或新形态继续冒险**：创建新的独立 PC CharacterSheet、CombatProjection 与 CombatantInstance；
3. **制造受控不死生物**：保留原死亡事实，创建独立 monster/NPC 实例及控制关系；不是 PC 复活。

不得新增第四张“以不死生物身份继续冒险”或第五张“自定义结果”卡。自定义只作为上述三种结果内部的依据或形态选择。只记录备注、但不改变死亡后对象的操作，应进入普通日志/备注，不进入死亡后结果流程。

### A-3 结果优先的 UX

交互顺序固定为：

```text
选择三种结果之一
→ 只显示适用法术与自定义依据
→ 处理该结果内最多一次必要分支
→ 显示简短、非阻塞规则提示
→ 填写必要操作与可选记录
→ 预览实际数据变化
→ DM 确认后原子提交
```

- 结果卡的第一次选择决定对象拓扑；选择法术后不得再次询问同一个结果问题。
- 默认只显示一行规则摘要和少量标签；完整候选规则放在“查看详细参考”中。
- 法术提示提供“使用建议值”与“自行填写”；偏离建议值只在预览中标记为 DM 裁定，不弹出阻塞确认。
- 必要操作始终展开：目标、最终 HP/新卡/Template、地图、先攻、继承、控制关系和 DM 原因。
- 可选记录默认折叠：施法者、法术位、材料、时间、灵魂和规则符合情况。
- 取消预览不得创建角色卡、实例、事件、控制关系、资源变更或存储写入。

### A-4 法术与推荐结果

具体法术在产品 UI 与本文中统一使用中文名。

| 法术 | 推荐结果 | 结果内提示与分支 |
|---|---|---|
| 回生术 | 恢复原身体 | 提示死亡时间、材料、老死、身体缺失与建议 HP；均可由 DM 覆写。 |
| 死者复活 | 恢复原身体 | 提示死亡时间、材料、死亡时是否为不死生物、必要身体部位与复活后影响；后遗症不自动按长休递减。 |
| 复生术 | 恢复原身体 | 提示死亡年限、老死、材料、身体恢复、中毒与复活后影响；不建立自动时间或后遗症引擎。 |
| 完全复生术 | 恢复原身体；或以新身体继续 | DM 首次选择的结果卡已决定路径：有遗体/恢复原实例走第一张卡；遗体不存在/新身体走第二张卡，不再二次询问。 |
| 转生术 | 以新身体继续 | 新身体子选项；创建独立新角色卡。种族结果可由 DM 指定、使用表格随机结果或不记录，不自动重算合法性。 |
| 克隆术 | 以新身体继续 | 新身体子选项；创建独立新角色卡。不追踪 120 日，不要求预登记克隆体；DM 确认“克隆体现在可用”即可。 |
| 活化死尸 | 制造受控不死生物 | 提示遗骨/遗体、骷髅/丧尸、数量、升环、命令与控制期限；Template 和结果由 DM 确认。 |
| 唤起亡灵 | 制造受控不死生物 | 提示夜晚、尸体、数量、Template、升环、命令与控制期限；支持 DM 自定义数量和 Template。 |

如果 DM 希望某个法术产生非推荐结果，应先选择实际需要的结果卡，再使用“自定义依据”记录“以该法术为基础的 DM 裁定”。正式法术模板不得为非标准结果额外制造交叉分支。

### A-5 新身体或新形态的三个子选项

“以新身体或新形态继续冒险”内部并列三个子选项，且只选择一次：

1. **普通新身体**：直接复用 v0.5.0 S2A 的独立新角色卡、新实例、选择性继承和旧卡保留能力；
2. **不死生物形态**：直接复用 v0.5.0 S2C 的独立新角色卡、新实例、选择性继承和玩家控制语义，但不再作为独立顶层结果；
3. **其他自定义形态**：复用同一后继角色创建合同，由 DM 填写形态说明，不增加新的对象拓扑。

三者都必须：

- 从旧 CharacterSheet 当前修订快照创建新 `characterId`、修订 1；
- 只复制 DM 勾选的字段，之后两卡完全独立；
- 保留原死亡实例和原卡；不自动归档、同步、覆盖或排他；
- 新 PC 只通过自己的 CombatProjection 加入战斗和产生战后候选；
- 以人类可读备注关联旧卡、新卡和事件 ID，不建立强 predecessor/successor Schema 耦合。

### A-6 受控不死生物

“制造受控不死生物”复用 v0.5.0 S2B 的独立 monster/NPC 实例、`controllerLink`、长期 `controlledEntities` 候选、地图摆放、先攻、命令与失控边界，并修正 UI 中文术语：新文案统一使用“受控不死生物/不死生物”，不改写 v0.5.0 冻结材料。

- 原死亡事实不撤销；原 CharacterSheet 不恢复、不接受该新单位的战后写回。
- 新单位必须拥有独立 ID、Template、HP、行动、地图、先攻和事件历史。
- 控制者可以关联当前角色/战斗单位；若 DM 不追踪长期控制者，允许只记录本场裁定，但不得把控制权默认为原 PC 玩家。
- 控制期限由 DM 管理。新操作不得把一次长休等同于 24 小时，也不得按现实时间自动推进。
- v0.5.0 既有 `one-long-rest` 数据保持可读，不自动改写；新操作使用 DM 管理的期限/状态记录。
- 同一遗体已产生后继单位时，系统提示重复来源；DM 明确覆写并填写原因后仍可继续。

### A-7 DM 裁定与可选资源记录

每条规则提示均允许：采用建议、DM 改判、不适用、不追踪、未知或稍后补充。没有施法者、法术位、材料、精确时间、尸体资格或灵魂记录时，系统仍允许 DM 提交结果。

法术位和材料只提供四种处理：

- 同步扣除当前已追踪资源；
- 只记录“DM 确认已消耗”；
- 不追踪；
- 自定义处理。

只有 DM 主动选择“同步扣除”时才修改资源。资源扣除、角色卡/实例创建、控制关系和结果事件必须在同一次确认中保持原子性；任何部分失败不得留下半完成状态。

### A-8 遗体防腐辅助提示

遗体防腐不是第九个主结果，也不单独改变角色生命阶段。它只作为尸体/死亡记录上的辅助提示，可记录作用对象、DM 认定的生效区间、是否影响腐烂/不死生物转化/复活期限及备注。

后续死亡处理显示该记录，但不自动计算有效死亡时间，也不阻止 DM 复活或转化。

### A-9 事件、存储与 v0.5.0 兼容

- v0.5.0 的 `pc.return-to-life.confirmed`、`pc.replacement.confirmed`、`pc.undead-successor.confirmed`、`combatant.controlled-undead.created` 及其关联数据必须继续可读、可导入和可展示。
- 旧 `pc.undead-successor.confirmed` 在新 UI 中归类为“以新身体或新形态继续冒险 / 不死生物形态”；不得改写旧事件或旧 CharacterSheet。
- 新操作不再创建独立的第四顶层结果；普通新身体、不死生物形态和其他自定义形态共享统一后继角色创建流程，并保存明确的形态子类型。
- 新 Session Schema 与新 copy-on-write storage key 的精确版本由 Implementation 在不破坏本 ABC 的前提下记录；不得就地改写 v0.5.0 或更早 key。
- 未知未来 Schema、损坏新 key、不完整对象引用和重复 event ID 必须安全拒绝，且不得覆盖旧数据。
- 所有确认均追加顺序事件；撤销使用补偿事件。新对象产生后续依赖事件时，不得破坏性撤销创建事实。

### 自动测试

- 当前全部自动测试回归。

### 浏览器与 Human Acceptance

使用隔离 origin 与合成夹具，不读取用户真实 localStorage。User/DM 至少确认：

- 三张卡比 v0.5.0 四张卡更清楚；
- 每个法术只有一个推荐结果，完全复生术由首次结果选择消除歧义；
- 默认提示简短，详细文本不会淹没操作；
- 缺少或忽略材料、时间、灵魂和资格信息时仍能完成 DM 裁定；
- 新身体三个子选项能覆盖 v0.5.0 S2A/S2C 与自定义形态；
- 旧 v0.5.0 不死生物 PC 记录仍能正确显示；
- 预览准确列出角色卡、实例、尸体、地图、先攻、控制关系和资源变化。
