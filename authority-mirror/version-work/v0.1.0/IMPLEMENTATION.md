## 实施选择

采用零依赖的浏览器原生 ES Module 单页应用：`index.html`、`src/app.js` 与 `src/styles.css`。状态使用浏览器 `localStorage` 持久化，JSON 文件提供完整导入/导出，Python 标准库仅用于本地静态服务和算法单元测试。

### 理由

当前执行环境没有 Node.js，不能可靠执行 Vite/Vitest 或安装 npm 依赖。原生模块可在任意现代浏览器本地运行，足以验证单一会话、事件、地图交互与恢复闭环，并避免引入未用于 v0.1.0 验收的基础设施。

### 替代方案与不采用理由

- React + TypeScript + Vite：组件与类型体验更好，但当前缺少 Node.js，无法构建、测试或锁定依赖；不做未经验证的假安装。
- 多页 HTML：会增大跨页面状态副本与覆盖风险，与单一 `CombatSession` Authority 不符。
- 纯最终 Snapshot：无法记录补偿撤销和人工修正，不符合 ABC。

### 版本、迁移与回滚

- 导出 Envelope 固定 `schemaVersion: "0.1.0"`；未来版本必须先显式迁移，较新版本拒绝导入。
- `localStorage` 的键使用单一命名空间；导入先解析与校验，再替换内存会话和存档。
- 回滚只删除或替换 Workspace 中候选源码；既有导出 JSON、事件与 Obsidian Authority 记录保留。

## 2026-07-31 局域网触控访问修复

首次手机访问 `http://<LAN-IP>:4173` 时只显示深色背景。原因是页面在非 HTTPS 的局域网 HTTP 上直接调用 `crypto.randomUUID()`；部分移动浏览器不会在非安全上下文暴露该 API，脚本在首次创建会话前失败，空 `#app` 因而没有被渲染。

已在 `src/app.js` 改为优先使用 `crypto.randomUUID()`、在其不可用时使用本地 UUID v4 兼容回退；`structuredClone` 也增加 JSON 深拷贝回退。回退不承担安全令牌或多人身份认证职责，仅用于单机本地会话 ID。使用局域网地址的浏览器复验已显示七标签和空白会话。
